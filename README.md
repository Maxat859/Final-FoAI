# QAMAL: PRISON BREAK — AI Educational Pixel Art Game

Учебная браузерная 2D-игра для QAIRU Final Project 2026. Главный герой Ерасыл исследует виртуальную тюрьму QAMAL-01 и знакомится с AI-алгоритмами через задания.

## Запуск

В GitHub Codespaces (или в папке проекта на компьютере):

```bash
python3 -m http.server 3000
```

Открой порт 3000 и нажми **НАЧАТЬ ИГРУ**. Не запускай HTML через `file://`: ES Modules и загрузка JSON могут блокироваться браузером.

## Готово в ветке feature/pixel-art-ui

- 14 оригинальных PNG 32×32, единый манифест спрайтов (26 sprite ID, включая повторные портреты)
- Canvas-карта 30×20, перемещение WASD/стрелки, коллизии со стенами/мебелью/NPC
- Fog of War, исследованная мини-карта и игровое меню (E — действие, M — карта, Esc — меню)
- CSP-замок и генератор 1000 досье от участника №2 (скопированы без изменения)
- Задания Python/Go для демонстрации интерфейса
- Байес: вычисления по изменяемым параметрам ALARM/NORMAL
- Виртуальные CCTV, поиск по 1000 досье, редактирование наблюдений, аудит
- IndexedDB с запасным localStorage для сохранения прогресса
- Интерфейсы Search / Minimax / Decision Tree и понятные сообщения, если нет подключённого алгоритма

## Что ещё должна предоставить команда

| Модуль | Ответственный | Статус интеграции |
| --- | --- | --- |
| BFS/DFS/UCS/A* | №1 | UI подготовлен, backend ожидается |
| CSP / Backtracking | №2 | подключён для игровых замков |
| Decision Tree / Metrics | №2 | UI подготовлен, backend ожидается |
| Minimax / Guard AI | №3 | UI подготовлен, backend ожидается |
| Frontend / Pixel Art / Bayes / CCTV / Dossier UI | №4 | реализовано в этой ветке |

Пока нет обученной Decision Tree, показанная оценка риска в досье — **временное правило интерфейса**, не настоящий ML-прогноз. Виртуальные камеры не используют настоящие видеозаписи.

## Тесты

```bash
npm test
```

Тесты используют встроенный тест-раннер Node 22. Публичный сервер и сторонние пакеты не нужны.

## Структура

- `assets/` — Sprite PNG + `manifest.json`
- `src/main.js` — запуск и интеграция
- `src/config.js`, `src/game/` — игровая карта, движение и миссия
- `src/algorithms/bayes.js` — Байес
- `src/ui/` — Canvas, окна, CCTV, досье, Training Lab
- `src/surveillance/`, `src/storage/` — досье, аудит, IndexedDB
- `tests/` — Node unit/integration tests
- `docs/art/style-guide.md` и `docs/modules/frontend.md` — документация №4

## Командная работа

`feature/shared-assets` и `feature/pixel-art-ui` — ветки участника №4. Pull Request #4 — черновик на проверку команды, `main` не изменён. После проверки другие участники интегрируют свои алгоритмы через согласованные интерфейсы и spriteId.
