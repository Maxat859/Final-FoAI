# QAMAL — Game Assets

Здесь хранятся все графические ресурсы игры QAMAL.

## Стиль
2D Top-Down Pixel Art

## Стандарты
- Формат изображений: PNG
- Размер игровых клеток: 32x32 px
- Прозрачный фон для персонажей и объектов
- Названия файлов: английские, маленькими буквами
- Пример: prisoner_idle.png

## Категории
- characters — персонажи
- environment — пол, стены, двери, мебель
- security — камеры и сигнализация
- ui — кнопки, иконки, панели
- effects — визуальные эффекты
